# C# Task Manager
A simple Task Manager project written in C#.

In order to run this file, install .NET SDK, and in the terminal go to the file it is in, and run "dotnet run".

This script will create a tasks.json file where you put the code, this is where all your tasks will be saved so you can use them multiple times.

It saves through uses with features such as, adding tasks, deleting them, completing them and configuring made tasks. You can customize each task with a name, description, priority, and a set due date that uses real time.

You can also search for tasks, and anything with what you search will appear.
